Flow Launcher gọn hơn Start Menu nhưng tốn gần 250 MB ổ cứng

Nhiều người vẫn giữ thói quen bấm phím Windows rồi gõ vào Start Menu vì ngại cài thêm phần mềm nền. Thực tế trên Windows 10 trở lên, việc rê chuột qua từng menu hay chờ tìm kiếm mặc định phản hồi chậm hơn hẳn thao tác gọi ô tìm kiếm nổi giữa màn hình. Với Flow Launcher bản 2.1.4 phát hành ngày 20/09/2026, bạn chỉ cần nhấn Alt Space, gõ vài ký tự và nhấn Enter để mở ứng dụng, tìm tệp hoặc tính nhanh. Muốn đổi phím tắt, bạn vào mục Hotkeys; còn muốn mở rộng tính năng thì cài thêm trong Plugin Store.

Hạng mục 1: Cài đặt và dung lượng thực tế

Theo tài liệu chính thức từ flowlauncher.com, bản 2.1.4 có hai lựa chọn tải về:

  • Bản Installer (EXE): nặng 97,07 MB, lưu cấu hình tại `%APPDATA%\FlowLauncher`, phù hợp khi cài cố định trên một máy.
  • Bản Portable (ZIP): nặng 196,46 MB, lưu dữ liệu mặc định trong thư mục `app-phiên bản\UserData`, tiện chép vào USB hoặc thư mục đồng bộ đám mây.

Nhược điểm lộ rõ ngay khi giải nén: vì đóng gói tự chứa (self-contained) kèm sẵn thành phần .NET nên dung lượng sau khi cài ước tính lên tới 250 MB. Con số này không nhỏ với một công cụ chỉ làm nhiệm vụ khởi chạy. Ngoài ra, phần mềm yêu cầu tối thiểu Windows 10 (dòng 1.20.x cũ mới hỗ trợ Windows 7) và chưa có mặt trên Microsoft Store, nên bạn tuyệt đối không tải các bản giả danh trên Store.

Nếu quen dùng dòng lệnh, bạn có thể gõ `winget install "Flow Launcher"` trong Terminal (hoặc dùng Scoop, Chocolatey) để kéo trực tiếp gói từ kho GitHub chính thức, tránh bấm nhầm link quảng cáo.

Hạng mục 2: Cảnh báo SmartScreen khi chạy lần đầu

Khi mở tệp vừa tải, Windows thường chặn lại bằng cảnh báo Microsoft Defender SmartScreen. Tài liệu dự án giải thích điều này xảy ra do phần mềm chưa đủ lượt tải để Microsoft tự động tin cậy, một số trình diệt virus bên thứ ba thậm chí còn báo nhầm. Nếu đã xác minh nguồn tải từ trang chủ hoặc GitHub chính thức, bạn bấm More info rồi chọn Run anyway để tiếp tục cài đặt.

Hạng mục 3: Phím tắt Alt Space và bộ 12 plugin lõi

Mặc định, Flow Launcher chạy nền ở khay hệ thống và bật lên khi nhấn Alt Space. Nếu tổ hợp này trùng với phần mềm khác trên máy, bạn mở phần cài đặt, tìm mục Hotkeys để đổi sang phím tắt thuận tay hơn. Giao diện cũng hỗ trợ Tiếng Việt trong mục Language.

Ngay khi cài xong, phần mềm đã có sẵn 12 plugin lõi gồm: Browser Bookmarks, Calculator, Explorer, Plugin Indicator, Plugins Manager, Process Killer, Program, Shell, System Commands, URL, Web Searches và Windows Settings. Nhờ đó, bạn gõ trực tiếp `Shutdown`, `Restart`, `Lock`, `Sleep`, `Hibernate` hay `Empty Recycle Bin` để điều khiển máy, hoặc nhấn F1 để bật Preview Panel xem trước tệp. Chi tiết hướng dẫn từng bước thiết lập và xử lý lỗi phát sinh đã được ghi lại đầy đủ trên ReviewLaptop để bạn đối chiếu khi cần.

Hạng mục 4: Mở rộng qua Plugin Store

Nếu 12 plugin mặc định chưa đủ, bạn mở Plugin Store ngay trong phần mềm để cài thêm tiện ích từ cộng đồng. Tiện ích đáng chú ý là Dialog Jump, cho phép tìm nhanh một thư mục rồi nhảy thẳng tới đường dẫn đó trong hộp thoại Open hoặc Save As của Windows.

Đổi lại sự tiện lợi của bộ lệnh gõ tắt và kho plugin mở rộng là mức tiêu tốn khoảng 250 MB dung lượng ổ cứng cho gói .NET đi kèm cùng thao tác vượt cảnh báo SmartScreen trong lần cài đầu tiên.
